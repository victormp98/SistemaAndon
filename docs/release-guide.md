# Guía de release

1. Ejecutar lint, build y tests.
2. Ejecutar auditorías npm.
3. Ejecutar `scripts/build-release.ps1`.
4. Probar `release/SistemaAndon` con el launcher.
5. Verificar health, login y descarga de reporte.
6. Copiar `SistemaAndon-Producto-Final.zip` a la USB.

La prueba definitiva debe hacerse en una PC Windows limpia sin Internet.
