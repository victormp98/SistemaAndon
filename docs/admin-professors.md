# Administración de profesores

Ruta: `/profesor/profesores`.

Sólo admin global puede:

- listar;
- crear;
- editar;
- activar/desactivar;
- conceder o retirar permiso admin;
- restablecer contraseña.

Protecciones:

- no se puede desactivar la propia cuenta;
- no se pueden retirar los propios permisos;
- no se puede dejar el sistema sin un administrador activo;
- reset y desactivación revocan sesiones.
