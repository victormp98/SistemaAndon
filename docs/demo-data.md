# Datos demo TEST

Ejecutar:

```powershell
npm.cmd run seed:demo
```

El comando es idempotente y restablece únicamente entidades cuyo nombre termina en `TEST`, además de las cuentas demo.

Usuarios: `admin`, `prof1`, `prof2`, `juanp`, `anag`, `carlosm`, `mariag`, `luisr`, `sofial`.

Incluye tres laboratorios, tres líneas, estaciones, simulaciones running/ready/paused/completed, órdenes OP-TEST, tickets, defecto, evento y paro.
